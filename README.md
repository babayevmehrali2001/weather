Hava proqnozu ucun backend yazilibdir, OpenWeatherMap API - dan datani cekir ve lazim olani seliqeye salib gonderiririk. Isleme prinsipi asagidaki kimidir: Fronted muraciet ederek datani alir OpenWeatherMap-den, daha sonra ise biz yazdigimiz responseye lazim olan fieldleri set ederek geri qaytaririq. 	/api/weather/current?city={city} - cari hava ucun 	/api/weather/forecast?city={city} -  gunluk proqnoz 	/api/weather/rain-probability?city={city} - yagis ehtimalini gosterir butun endpointlerde taskda gosterilen kimi reponse geri qaytarir
